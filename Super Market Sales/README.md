# 🛒 Super Market Sales Dashboard

## 📌 Project Overview
This project analyzes the Supermarket Sales dataset using Microsoft Power BI. 
The dashboard provides interactive visual insights into sales performance, customer behavior, product trends, and branch performance.

---

## 📂 Dataset Used
File: supermarket_sales - Sheet1.csv  
Tool: Power BI Desktop  

---

## 🎯 Objectives
- Analyze total sales and revenue
- Identify top-performing product lines
- Compare branch and city performance
- Understand customer purchasing behavior
- Evaluate payment method usage
- Analyze customer ratings

---

## 📊 Dashboard Features
✔ Total Sales, Gross Income, Quantity Sold  
✔ Sales Trend by Date  
✔ Product Line Analysis  
✔ Branch-wise & City-wise Comparison  
✔ Customer Type & Gender Analysis  
✔ Payment Method Distribution  

---

## 🧮 DAX Measures Created
- Total Sales = SUM(Total)
- Total Profit= SUM(PROFIT)
- Total Quantity = SUM(Quantity)
- Total Gross Income = SUM(Gross Income)
- Average Rating = AVERAGE(Rating)

---

## 🛠 Tools Used
- Power BI Desktop
- Power Query
- DAX
- CSV Dataset

---

## 📁 Project Files
- Super Market Sales.pbix
- supermarket_sales - Sheet1.csv

---

## 📈 Key Insights
- Some product lines generate higher revenue.
- Member customers contribute more consistent sales.
- Evening hours show higher sales volume.
- E-wallet and Cash are commonly used payment methods.
- Certain branches outperform others.
