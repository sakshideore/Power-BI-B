# Personal Finance Management Dashboard

## 📌 Project Overview

The Personal Finance Management Dashboard is built using Microsoft Power BI to analyze and monitor personal financial transactions. 

This dashboard provides interactive insights into income, expenses, savings, and spending patterns, helping users better understand their financial health and make informed budgeting decisions.

---

## 📂 Dataset Information

- Dataset File: Dataset.xlsx
- Tool Used: Power BI Desktop

### Key Fields in Dataset:
- Date
- Month
- Category
- Income/Expense Type
- Amount
- Payment Mode
- Description

---

## 🎯 Project Objectives

- Track total income and total expenses
- Monitor monthly financial trends
- Identify highest spending categories
- Calculate net savings and savings percentage
- Analyze payment mode usage
- Improve financial visibility through interactive visuals

---

## 📊 Dashboard Features

### 🔹 Financial Summary
- Total Income
- Total Expenses
- Net Savings
- Savings Percentage

### 🔹 Monthly Analysis
- Income vs Expense by Month
- Monthly trend comparison
- Month slicer (Jan–Dec properly sorted)

### 🔹 Category Analysis
- Expense breakdown by category
- Highest spending categories
- Contribution of each category to total expenses

### 🔹 Payment Mode Analysis
- Spending distribution by payment type
- Transaction frequency by payment method

## ✅ Conclusion

This project demonstrates how Power BI can be used to transform raw financial transaction data into meaningful and interactive visual insights. 

The dashboard enables clear tracking of income, expenses, and savings trends, supporting better financial planning and decision-making. 

Through this project, skills in data cleaning, data modeling, DAX calculations, and dashboard design were applied to build a professional-level financial analytics report.
